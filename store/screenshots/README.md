# Screenshots

Estes 3 arquivos (`01_menu.png`, `02_gameplay.png`, `03_game_over.png`) são
**mockups** das telas do jogo — recriados em HTML/CSS com as mesmas cores e
textos do app, renderizados em 1080x1920 (formato retrato aceito pelas
lojas), já que este ambiente não tem emulador Android nem Xcode para
capturar screenshots reais.

Antes de publicar, troque por capturas reais rodando o app num
emulador/dispositivo (`flutter run` + botão de captura de tela, ou
`flutter screenshot`). As lojas costumam recusar screenshots que não
refletem o app de verdade.
